⚡ 학습의 대원칙

현명한 반복은
당신을 천재로 만듭니다

  1. 반복 앞에서 안 외워지는 것은 없습니다 아무리 어려운 내용도 반복을 거치면 결국 완전히 내 것이 됩니다.
  2. 결국 목차도 외워져 있어야 합니다 내용을 익히는 과정에서 목차 자체까지 또렷이 머릿속에 자리잡혔을 때 학습이 비로소 완성됩니다.
  3. 다양함이 기억을 굳힙니다 학습 카드 안의 내용이 다양할수록 두뇌에 더 구조적으로 저장됩니다.
  4. 콘텐츠는 계속 진화합니다 모든 목차·학습 카드·내용은 최적의 형태가 될 때까지 끊임없이 추가·수정·삭제됩니다.

1
챕터 카드 — 내 학습을 한눈에

홈 화면에서 내가 구독 중인 챕터·학습 중인 챕터가 위에 옵니다. 카드 우측 상단의 D-N은 남은 학습 기간이에요.

팁 카드를 누르면 챕터로 들어가요. 미구독 챕터도 무료 목차는 열려요.
2
목차·암기할 항목 펼치기

챕터 안에서 목차를 누르면 그 안의 암기할 항목이 펼쳐지고, 암기할 항목을 누르면 본문(이미지·텍스트·링크)이 보입니다.

팁 목차 안에 암기할 항목을 펼치면 이미 펼쳐진 다른 항목의 내용은 자동으로 닫혀요 — 한 번에 하나에 집중.
3
⤴ 패스 — 똑똑한 자동 분류

목차 오른쪽 ⤴ 패스를 누르면 맨 위 카드가 사라져요. 그 카드는 "내가 챕터 안에서 한 번이라도 펼쳐봤는지"에 따라 자동으로 분류됩니다.

안 펼치고 패스
"안다" 신호 → 자동으로 ● 다지기 등록
펼쳐본 뒤 패스
"다시 봐야 했다" → 미암기 (★ 표시 누적)
📑 목차 안에 3개 탭 — 같은 카드를 다른 시각으로
new — 아직 ● 등록 안 한 카드만. 처음 학습용
★ 별표 — 한 번이라도 틀렸던 카드 (★ 많은 순). 약점 집중
all — 모든 카드 + 박스 위치 라벨 (오늘/내일/4일/...). 전체 점검용
모두 패스 → 🎉 자동 재시작 미암기로 분류된 카드들만 다시 위로 올라와서 집중 복습할 수 있어요. 챕터를 나갔다 들어오면 "펼친 기록"은 초기화 — 늘 새로운 한 회로 시작합니다.
다시 정리 "안 펼치고 패스 = 안다" / "펼친 뒤 패스 = 모른다". 펼친 적 있는 카드는 ★ 별표 탭에 누적돼서 약점만 모아 복습 가능.
4
꾹눌러서 ● 직접 표시

학습 카드를 0.6초 이상 꾹누르면 바로 "● 다지기"에 등록됩니다. 다시 꾹누르면 해제. 휴대폰이 살짝 진동해서 표시된 걸 바로 알 수 있어요.

패스와 차이 패스(STEP 3)는 펼침 여부를 보고 자동 분류 + 카드가 사라짐. 꾹누르기는 카드가 안 사라지고 ● 표시만 즉시 토글 — "이건 확실히 안다" 거나 "이건 다시 봐야 한다" 를 명시적으로 정할 때 쓰세요.
5
● 다지기 — 6박스 자동 간격 반복

챕터 상단 ● 다지기 버튼을 누르면 ● 등록한 카드를 6개 박스로 보여줍니다. 오늘 학습 박스만 펼쳐져 있고, 위에서부터 차례로 진행하면 됩니다.

📦 6박스 구조
오늘 학습 오늘 봐야 할 카드 (기본 펼침). 패스로 위로 올림
내일 학습 1일 후에 다시 오늘 학습으로 자동 등장
4일 후 4일 후에 자동 등장
8일 후 8일 후에 자동 등장
16일 후 16일 후에 자동 등장
32일 후 32일 후 — 거의 다 외운 단계
⤴ 오늘 학습 패스
안 펼치고 패스 → 다음 박스로 자동 진급 (오늘 → 내일 → 4일 → 8일 → 16일 → 32일)
✨ 미래 박스: 펼침→접음
"확인해보니 모름" 신호. 보랏빛 dissolve 후 오늘 학습으로 강등 → 처음부터
📊 오늘 암기 클리어율 화면 상단에 오늘 진급한 카드 수가 실시간으로 표시됩니다 — 오늘 박스가 0이 되면 🎉
🕛 자정 자동 정렬 내일 학습/4일 후 등 모든 미래 박스 카드는 next_review 날짜가 되면 자동으로 오늘 학습 박스에 나타납니다. DB 변경 없이 즉시 노출.
영어 단어는 🔊 발음 듣기 학습 카드 제목 옆 🔊 버튼으로 바로 들을 수 있어요.
5+
🎤 음성 / ✏️ 첫글자 퀴즈 — 단어와 뜻을 빠르게 각인

특정 챕터(한국사·영단어처럼 짧은 답이 있는)에서는 다지기 상단에 두 가지 퀴즈 모드가 나타납니다. 카드 터치 학습 전에 가볍게 단어-뜻 연결을 확인해보세요.

🎤 음성 퀴즈 (4초)
제목을 본 뒤 4초 안에 말로 답. 브라우저 음성 인식이 자동 채점. 차에서·걷기·집안일 중에도 가능.
✏️ 첫글자 퀴즈
정답의 첫 글자와 가짜 글자 2개 중 선택. "안다고 착각" 차단 — 가벼운 commitment 강제.
📸 사진 스냅샷 결과
정답/오답 시 카드 전체가 초록 또는 빨강으로 변하고, 단어와 뜻이 크게 위·아래로 표시됩니다. 글자 라벨 없이 색깔만 — 단어-뜻 페어가 사진처럼 머리에 각인.
🔊 음성 모드 (자동 + 문제 읽기 ON)
차에서·운동 중에 핸즈프리로 학습 가능:
📢 TTS가 제목 읽음 → 🎤 4초 listening → 답
🎵 띵동(정답) / 삑(오답) 신호음
📢 TTS가 뜻만 명확히 발음 → 단어-뜻 페어 청각 각인
➡️ 자동으로 다음 카드
퀴즈는 SRS 박스 변경 안 함 단순 단어-뜻 빠른 연결 확인용. 박스 진급은 카드 터치 학습 ✓/✗로만. 우상단 카운트가 줄어 0이 되면 "퀴즈 클리어!" toast.
오답은 반복 정답만 카운트 감소. 틀린 카드는 다시 풀에 남아 다음 번에 또 등장 (방금 본 카드는 후순위).
퀴즈 ↔ 터치 학습 sync 카드 터치로 ✗ 누르면 그 단어가 다시 퀴즈 풀에 등재. ✓ 누르면 풀에서 제외 (advance). 한 번 클리어로 끝나지 않고 깊은 학습과 연동.
활성 챕터에만 노출 선생님이 콘텐츠 만들 때 "🎤 음성 퀴즈 활성화" 체크한 챕터만. 컨벤션: 학습 카드 첫 번째 항목 = 정답 (예: "abundance" → 첫 항목 "풍부함").
6
👤 내 계정 — 구독·포인트·추천 코드

홈 우측 상단 👤 를 누르면 내 구독 현황·남은 일수·포인트·추천 코드까지 한 화면에서 확인할 수 있어요. 비밀번호 변경도 여기서.

📋 코드 / 🔗 링크 둘 다 복사 버튼이 있어요. 친구에게 보내면 가입 시 자동 연결.
7
결제·포인트 사용으로 챕터 열기

미구독 챕터에서 "결제" 또는 "포인트 사용" 버튼으로 30일 열람권을 받습니다. 이미 구독 중이면 같은 버튼이 30일 연장으로 작동해요.

주의 챕터마다 가격이 다릅니다 (1,000원~). 결제 전 카드의 금액을 확인하세요.
