## 권장 포맷

- **WebP** 권장 (PNG 대비 50~80% 가벼움)
- 압축 도구: [TinyPNG](https://tinypng.com) 또는 [Squoosh](https://squoosh.app)
- 최종 파일 크기 목표: **장당 50~200KB**

## 스타일 가이드 (모든 이미지 일관 적용)

- 배경: 깊은 네이비 `#0a0a1a` → `#16213e` 그라데이션
- 강조색: 진홍 `#e94560`, 호박 `#ffb347`
- 톤: 모던 미니멀, 다크 모드, 부드러운 글로우
- 스타일: 이소메트릭 또는 플랫 일러스트 (사진 X)
- 글자 직접 렌더링 X — 글자는 HTML/CSS로 따로
