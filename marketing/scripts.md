# 원페이지 학습 — 마스터 영상 스크립트 5편

Vrew 에 바로 붙여넣어 AI 음성·자막을 자동 생성하기 위한 마스터 스크립트.

⚠️ **중요**: Vrew 는 붙여넣은 모든 텍스트를 음성으로 읽습니다.
그래서 각 영상은 **두 블록**으로 나눠 두었어요:

1. **Vrew 붙여넣기용 음성 텍스트** — 화자가 말할 문장만. 이걸 복사해서 Vrew 에 붙여넣으세요.
2. **화면 매칭 표** — 어느 음성 블록 위에 어떤 영상을 올릴지. Vrew 안에서 B-roll 드래그할 때 참고.

---

## 공통 브랜드 톤

- **톤**: 해요체. 친근하지만 신뢰감 있는.
- **금기어**: "혁신적", "최고의", "완벽한" (과장)
- **자주 쓰는 말**: "한 페이지", "● 암기", "패스", "학습 카드", "목차"
- **슬로건**: "현명한 반복은 당신을 천재로 만듭니다"
- **CTA URL**: vipup.site/onepage

### 필요 B-roll
- 시작 후크용 1~2초 영상 (한숨 쉬는 사람, 책상, 단어장 위주 — 무료 스톡: Pexels/Pixabay)
- 앱 홈 화면 캡쳐 (이미 guide-media에 01-home.mp4 있음 — 재활용)
- 학습 페이지 화면 녹화 3초
- 패스 누르는 동작 (guide-media/03-pass.mp4)
- 최종 CTA 카드 (Filmora 정적 이미지)

### Filmora 강조
- 0~1초: 큰 자막 "200개? 외워질까요?" (충격 후크)
- 3~5초: 슬로건 자막 "한 페이지가 곧 시험 범위" 강조 박스
- 마지막 3초: QR 코드 + URL 정지 화면
- BGM: 잔잔하다가 13초쯤에 비트 올라가는 무료 음원

### 변형 안 (A/B 테스트)
- 후크를 "단어장 앱 100개 다운로드, 외운 단어는 0개" 처럼 자조적으로
- 후크를 결과 자랑형으로 "한 달에 챕터 5개 끝낸 비결"
